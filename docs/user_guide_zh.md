# RevertScope 本地使用指南

软件版本1.0.0；分析方法0.2.0；结果schema2.0.0。仅支持有独立生物学重复的bulk RNA-seq原始基因计数。

## 启动与示例

双击项目根目录的“启动RevertScope.cmd”，浏览器打开本机地址。也可在项目根目录运行：

```powershell
.\scripts\r.ps1 scripts/run_app.R
```

默认地址为 http://127.0.0.1:8765 。关闭启动窗口可停止服务。已保存项目不会因此消失；正在运行的任务应先在软件内取消。

首页“查看真实示例”打开GSE208041既有结果，不重新计算。“查看多干预示例”打开固定万基因模拟，支持查看两个干预及直接比较。真实示例为同一终点共同处理，不是纵向恢复；原研究29-mer及批次信息缺失限制仍适用。模拟不是另一真实案例。

## 导入与运行

1. 点击“新建分析”，可先下载计数和样本模板。计数表首列为唯一gene_id，其余列为唯一sample_id；样本表至少有sample_id、group。支持CSV、TSV和XLSX。
2. 上传两张表，检查预览及行列数。将实际组名映射到参考C、扰动D和D背景下干预T；每个组至少3个独立生物学重复。
3. 根据实验记录确认原始计数来源和独立重复；整数检查不能自动证明计数来源。TPM、FPKM、log表达不能取整使用。配对、纵向等设计不能按独立样本硬算。
4. 存在实际batch列时保留固定批次。软件拒绝不可估计的组别/批次混杂设计。不要为得到结果删除真实批次。
5. 高级设置中四阈值均为log2单位，默认δD=0.75、εR=0.5、δM=0.5、ε0=0.25。它们是预设，不是通用生物学标准。
6. 点击“运行分析”才创建分析版本。任务读取固定的输入副本；连续点击不会重复排队。取消会停止计算子进程，取消/失败不会生成成功结果，修正后可再运行。

计数缺失、样本名错误或重复ID应回源文件修正后重新上传；软件不静默补零、取整、删样本或合并身份。

## 阅读结果

“响应总览”显示每个干预的全体输入、保留、过滤、两类未确定原因和五个正式类别。类别为0是有效结果，不是模块缺失。地图默认保留全部有效估计，横轴d=D−C，纵轴t=T−D；t=−d表示r=T−C=0。参考容许带是参数区域，不是置信带，点落入其中不能自动获得恢复声明。

搜索、框选、表内分页排序和类别筛选只改变视图，不重新拟合、不缩小检验族，也不产生新的正式发现集合。点击图点或结果表可查看同一gene_id、干预和分析版本的详情。

“基因详情”将原始计数/模型输入logCPM样本展示与模型效应分开。有批次时样本图未额外调整，不能将图中组均值视为批次调整后的模型估计。95%区间是普通边际moderated-t区间，不是逐基因分类正确概率。

- 原始扰动未获支持：没有足够证据支持原始偏离，不是证明没有扰动。
- 分类证据不足：尚不能共同支持类别必要条件，不是证明干预无效。
- 未发生有意义改变：这是有等效证据支持的正式类别，不能用T−D“不显著”代替。
- 低表达过滤：没有进行该基因的分类推断，不是无变化。

默认是完整声明族的主BY结果。探索性BH仅显示规范对象已经提供的方向/类别统计字段，没有浏览器临时拼出的BH正式分类；切换视图不会覆盖主结果。

多干预比较显示相同gene_id在各干预的状态与效应；T_A−T_B是单独族校正的直接比较。“A有声明、B没声明”不能证明“A特异有效”。

小样本和窄等效范围下可能大量未确定。既有n=3模拟情景的统计功效尤其有限，不能以低错误率掩盖未检出，也不能以没有恢复声明推断药物无效。

## 保存、重开和导出

“保存视图”保存字体、标签、筛选及选择，统计结果不变。“重新运行”使用保存的输入与配置实际建立新分析；“修改设计并新建版本”保留旧结果，并记录参数变化。

项目自动包含输入副本、规范结果、参数、视图和分析历史。下载“可重开项目包”，可在下次启动后通过“打开项目”上传恢复。项目包不会自动执行脚本，越界路径及不支持的文件类型会被拒绝。中文和空格目录受支持。

全量TSV/CSV包含所有输入基因和计划干预；当前筛选表包含明确范围，不是浏览器当前页。候选表只包含主BY支持的参考内恢复/部分回调，零候选时仍有表头。下载名带分析身份，表中另有方法与范围字段。

SVG文字及图形可继续编辑；PDF保留文字和矢量图形；PNG用于预览。字号、尺寸、点大小和标签设置与统计参数分开。字体使用本机字体，不分发字体文件，目标电脑缺少同名字体时需替换，不能保证任意编辑器完全一致。

离线HTML报告包含静态图、概览、候选查看、设计及参数，不需要R/Shiny继续运行，不需要外网。报告仅用于查看，不支持重新计算。完整成果包另附原始输入副本、配置、样本映射、完整检验族、版本、校验和及相对路径rerun.R；使用锁定R环境运行复算脚本，不能将结果查看冒充重新计算。

软件默认只监听127.0.0.1，JS/CSS来自本地依赖，不调用在线注释、模型API或遥测。不提供药效总排名、治愈结论或自动机制解释。

长基因ID在图上使用固定缩写及ID哈希后缀，完整gene_id保留在表格、悬停和规范结果中；缩写不用于关联或统计。当前按唯一gene_id查看，不提供额外的symbol注释导入，不以重复symbol替代唯一ID。

重新上传文件会清除来源与独立重复的勾选，需要对新的输入重新确认。取消会停止本次实际R任务并保存取消记录；若计算已经完成，则以已保存的实际状态为准。取消或失败后可以重新运行，旧成功版本保留。
