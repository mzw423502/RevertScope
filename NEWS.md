# RevertScope 1.0.0

- Adds validated CSV, TSV and XLSX import for independent-replicate bulk RNA-seq counts.
- Fits linked perturbation, intervention and residual contrasts in one limma-voom model.
- Provides prespecified evidence-aware response classes with primary BY adjustment.
- Supports multiple intervention groups and direct intervention contrasts.
- Delivers a local Shiny interface, command-line workflow, tables, vector figures, reports and reopenable projects.
- Includes locked dependencies, simulated examples, public-case retrieval metadata and 43 release checks.
